The payload in `companion.txt` is generated by Guild OS v1.9.3, commit a9ab157, using its own fake members and real CompanionExport and LibDeflate modules. From an addon checkout, regenerate it with:

```sh
lua -e 'ADDON="."' tools/companion-payload.lua > companion.txt
```

`guild.lua` wraps that exact string in WoW SavedVariables syntax, with `__companionAt = 1754400000`. `personal.lua` adds `__companionSelf = true` to exercise personal-pack rejection.

The tool emits ANNIVERSARY, payload v14 and addonVersion 0.46.0, despite the checkout version being v1.9.3. The decoder test uses the bytes unchanged. The normalization test explicitly changes only the decoded game to FOREVER. Changing the tool's three client stubs (isAnniversary false, WOW_PROJECT_ID 99, and build 1.60.1/interface 16001) failed its own assertion at line 227, "an Anniversary client did not say so". No further changes were made. A genuine Forever capture is pending creation of the guild.
