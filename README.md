# wow-forever

Guild tooling for a World of Warcraft: Forever guild: a Discord bot for recruiting, roster, loot council and member Q&A, plus a reader that brings in-game guild data (from the Guild OS addon's saved variables) to the bot.

Specs live in `openspec/`.

The gateway bot needs View Audit Log for recruiting stage updates. A missing permission or failed startup permission check emits the recruiting error alarm.
